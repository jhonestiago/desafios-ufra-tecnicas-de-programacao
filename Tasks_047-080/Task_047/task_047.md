# Task 47

## PT

Faça um algoritmo/programa que leia um número N e imprima "F1", "F2" ou "F3", conforme a condição:

- "F1", se N < 10;
- "F2", se N = 10;
- "F3", se N > 10.

## EN

Create an algorithm/program that reads a number N and prints "F1", "F2", or "F3" according to the condition:

- "F1", if N < 10;
- "F2", if N = 10;
- "F3", if N > 10.
