# Task 011

## PT

Elabore um algoritmo/programa que calcule e mostre a taxa de consumo em km/l que um carro tem em um deslocamento. Devem ser criadas variáveis para a distância percorrida (em kilômetros), a quantidade de litros consumidos e o valor da taxa de consumo (em km/l). O cálculo é feito pela fórmula:

```plaintext
taxaDeConsumo = distancia / litros
```

## EN

Develop an algorithm/program that calculates and displays the fuel consumption rate in km/l that a car achieves during a trip. Variables should be created for the distance traveled (in kilometers), the amount of fuel consumed, and the value of the consumption rate (in km/l). The calculation is performed using the formula:

```plaintext
consumptionRate = distance / liters
```
