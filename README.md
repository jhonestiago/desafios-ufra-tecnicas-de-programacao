# Tecnicas de Programação

Repositório dedicado às soluções das listas de exercícios da disciplina **Técnicas em Programação** do curso de **Engenharia Ambiental e Sanitária** da UFRA - Campus Capanema.

## 📘 Objetivo
Reunir resoluções organizadas, facilitando o acompanhamento e revisão do aprendizado.

## 🔧 Conteúdo

### Lista de Exercícios I
- Lógica de Programação  
- Variáveis  
- Estruturas Condicionais  
- Laços de Repetição  
- Funções  
- Módulos  
- Vetores e Matrizes  

### Lista de Exercícios II
- Programação Orientada a Objetos (POO)  
- Interfaces Gráficas (GUI)
