# Task 20

## PT

Qual o valor de saída para x nos pseudocódigos abaixo?

(1)

```plaintext
ALGORITMO Valor_X;
VAR
    REAL x;
INICIO
    IMPRIMA “Valor de x”;
    x <- ((25 + 100 / 2) ^ 2 ) - 1;
    x <- x * x / 2;
    IMPRIMA x;
FIM
```

(2)

```plaintext
ALGORITMO Valor_X2;
VAR
    REAL x;
INICIO
    x <- (8 ^ 2) % 3;// O símbolo % representa o resto da divisão
    x <- x + 2;
    IMPRIMA x;
FIM
```

(3)

```plaintext
ALGORITMO Valor_X3;
VAR
    REAL x;
INICIO
    x <- 8;
    x <- x - 1;
    x <- x * 2;
    x <- x / 2;
    x <- x + 1;
    IMPRIMA x;
FIM
```

```plaintext
ALGORITHM Value_X;
VAR
    REAL x;
BEGIN

END
```

