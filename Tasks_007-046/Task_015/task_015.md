# Task 15

## PT

Escreva um algoritmo para solucionar e exibir o resultado da seguinte questão: um pendrive pode armazenar 8 GB de dados, sabendo que ele já está armazenando 3584 MB, quanto esse pendrive ainda pode armazenar em GB?

## EN

Write an algorithm to solve and display the result of the following question: a pendrive can store 8 GB of data, knowing that it's already storing 3584 MB, how much space can this pendrive still store in GB?
