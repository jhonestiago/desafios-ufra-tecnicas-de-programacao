# Task 36

## PT

Faça um algoritmo/programa que receba os coeficientes a, b e c de uma equação do 2º grau ax^2 + bx + c = 0 calcule e mostre os valores de delta e das raízes da equação.

$$
\Delta = b^2 - 4ac \\
\ \\
x^\prime = \frac{−b + \sqrt{\Delta}}{2a} \\
\ \\
x^{\prime\prime} = \frac{−b − \sqrt{\Delta}}{2a}\\
$$

\ \\
