# Task 21

## PT

Crie um algoritmo/programa que receba a largura e o comprimento de um lote de terra e mostre a área total existente. Não se esqueça de mostrar os valores de todas as variáveis usadas no algoritmo/programa. Use a fórmula:

```plaintext
areaDoLote = largura * comprimento
```

## EN

Create an algorithm/program that receives the width and length of a piece of land and shows the total area. Don't forget to display the values of all variables used in the algorithm/program. Use the formula:

```plaintext
landArea = width * length
```
