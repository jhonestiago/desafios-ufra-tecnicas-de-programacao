# Task 17

## PT

Crie um algoritmo/programa que receba três nomes quaisquer e os mostre na tela na ordem inversa da que foi fornecida.

```plaintext
Exemplo de entrada: Ana, Bruno e Caio
Exemplo de saída: Caio, Bruno e Ana
```

## EN

Create an algorithm/program that receives three arbitrary names and displays them on the screen in reverse order from the one provided.

```plaintext
Example input: Ana, Bruno and Caio
Example output: Caio, Bruno and Ana
```
