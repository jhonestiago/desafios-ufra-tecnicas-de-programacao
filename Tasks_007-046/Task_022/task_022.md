# Task 22

## PT

Faça um algoritmo/programa que receba a quantidade e o valor de três produtos, no seguinte formato: quantidade1, valor1, quantidade2, valor2, quantidade3, valor3. O algoritmo/programa deve calcular esses valores seguindo a fórmula total:

```plaintext
formulaTotal = quantidade1 x valor1 + quantidade2 x valor2 + quantidade3 x valor3
```

O valor total deve ser apresentado no final da execução do algoritmo/programa.

## EN

Create an algorithm/program that receives the quantity and value of three products, in the following format: quantity1, value1, quantity2, value2, quantity3, value3. The algorithm/program should calculate these values following the total formula:

```plaintext
totalFormula = quantity1 x value1 + quantity2 x value2 + quantity3 x value3
```

The total value should be presented at the end of the algorithm/program execution.
